# 观测数据质检清单

拿到一次外业数据，按下面几条过一遍，任何一条不通过就整段作废，不要"挑着用"。

## 完整性

- [ ] 观测时长达到计划时长的 90% 以上
- [ ] 采样间隔全程一致，没有中途重启留下的断点
- [ ] 关键字段（时间、坐标、C/N0、伪距）无空值

## 连续性

- [ ] 相邻历元伪距差小于 200 m
- [ ] 相邻历元载波相位差与伪距差自洽
- [ ] 钟差全程单调，没有不明跳变

## 一致性

- [ ] 同一台站不同天的天线编号一致
- [ ] 数据文件里的天线高与外业记录一致
- [ ] 接收机钟差与 UTC 偏差在 1 ms 以内

## 可追溯

- [ ] 原始文件已归档，文件名包含站点、日期、时段
- [ ] 外业记录表、站点照片、质检结论在同一个目录
- [ ] 异常时段在数据里有明确的标记，而不是靠记忆

> 质检没过就重测。数据是用来支撑结论的，掺了水的结论比没有结论更危险。
