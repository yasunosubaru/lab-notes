# 外业记录规范：GNSS 台站

野外台站最费时间的不是采数，是把"当时到底发生了什么"记下来。这份规范把一次
外业拆成三段：进场、观测、撤场，每段都要留下能复现的证据。

## 进场

- 记录站点坐标、天线编号、接收机序列号，三者对不上就不要开机
- 供电方式（市电 / 太阳能 / 电池）、电压、是否有备用电源
- 天气：云量、能见度、气温、露点；雷雨或强对流天气直接取消观测
- 天线安装高度、方位角、真北方向偏差；偏差超过 0.5° 必须在记录里写明

## 观测

按 1 Hz 原始采样、30 s 历元解算，记录：

| 字段 | 说明 |
| --- | --- |
| PRN | 使用的卫星编号 |
| C/N0 | 载噪比，dB-Hz，逐历元记录 |
| 伪距 | 米，保留到 0.01 |
| 载波相位 | 周期，保留到 0.001 |
| 钟差 | 秒，对比接收机时钟与外部 UTC |

异常判据：

- C/N0 连续 5 个历元低于 25 dB-Hz，标记遮挡
- 伪距跳变超过 2 m 且载波相位同步跳变，标记周跳
- 钟差超过 1 ms，标记时钟异常，优先怀疑接收机温漂

## 撤场

- 导出原始观测文件（rinex 3.04 或厂商原格式），当场校验能重新解析
- 记录拆装顺序、耗材消耗、异常现象的口述记录
- 站点照片：天线全景、近景、供电设备、周边遮挡物

## 复盘

观测数据回来后按同样的模板做一次复盘，标出哪些时段的数据不可用、为什么。
没有复盘记录的数据，等于没有数据。
